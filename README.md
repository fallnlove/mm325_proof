# A lower bound of 25 for ⟨3, 2, 5⟩ matrix multiplication

This repo contains complete Lean 4 proof of Theorem 1 from the accompanying proof note:
for **every field K** and **every positive integer m**, the tensor rank of
3-by-2 times 2-by-m matrix multiplication is strictly greater than 24m/5.
The former m = 5 theorem is retained as a corollary. The Lean 4 proof was generated by GPT-6 Astra.

## Build and audit

With elan installed, run from this directory:

```bash
lake exe cache get
lake build
lake env lean Audit.lean
```

Pinned versions: Lean 4.19.0 and mathlib v4.19.0.

All proofs are in `MatrixMultiplicationLowerBound25.lean`.

## Main statements

All names below are in namespace `MatrixMultiplicationLowerBound`.

- `matrixMultiplicationRank K m` is the minimum length of an exact bilinear
  decomposition. Existence of such a decomposition is proved using the
  ordinary entrywise algorithm; the minimum is attained.
- `matrixTensorRank K m` is the minimum length in the ordinary matrix model.
  `rank_eq K m` proves `matrixMultiplicationRank K m = matrixTensorRank K m`.
  The proof uses conversions in both directions, preserving the length exactly.
- `theorem_one_tensorRank K m hm` states the strict rational inequality
  directly for `matrixTensorRank K m`.
- `theorem_one K m hm` proves `24 * m < 5 * matrixMultiplicationRank K m`,
  where `hm : 0 < m`.
- `theorem_one_rational K m hm` proves
  `(24 * (m : ℚ)) / 5 < (matrixMultiplicationRank K m : ℚ)`.
- `theorem_one_rounded K m hm` proves
  `24 * m / 5 + 1 ≤ matrixMultiplicationRank K m`. Here `/` is natural-number
  division, so the left side is floor(24m/5) + 1.

## Audit

`Audit.lean` prints the statements and their transitive axiom dependencies.
The verified axioms are only the standard Lean axioms:
`propext`, `Classical.choice`, and `Quot.sound`.
There are no proof placeholders, user-declared axioms, or `native_decide`.
`verification.txt` records the build, audit, and source SHA-256.
